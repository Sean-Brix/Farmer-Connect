# USER PROFILE MANAGEMENT

## User Profile Page (Client View)

[IMAGE PLACEHOLDER: screenshot of user profile page]

- This page allows logged-in users to view and edit their personal information.
- Accessible by: All Authenticated Users

**Steps / How to Use**
1. Log in to your account
2. Navigate to Settings or click your profile picture
3. Select "Profile" or navigate to `/settings/profile`
4. View your current profile information including:
   - Profile picture
   - Username
   - Email address
   - First Name
   - Last Name
   - Contact Number
   - Address
   - RSBSA Number (for farmers)
5. To edit, click "Edit Profile" button
6. Update the fields you want to change
7. Click "Save Changes" button to apply updates

**Notes**
- Username and email cannot be changed after registration (system restriction)
- Profile picture can be uploaded in common image formats (JPG, PNG)
- Changes are saved immediately upon confirmation
- Some fields may be required and cannot be left empty

## Upload/Change Profile Picture

[IMAGE PLACEHOLDER: screenshot of profile picture upload]

- Users can upload or change their profile picture.
- Accessible by: All Authenticated Users

**Steps / How to Use**
1. Navigate to your Profile page
2. Hover over your current profile picture
3. Click "Change Photo" or the camera icon overlay
4. Select an image file from your device
5. Preview the selected image (if cropping is available, adjust as needed)
6. Click "Upload" or "Save" to confirm the change
7. Your new profile picture will appear throughout the system

**Notes**
- Supported formats: JPG, JPEG, PNG
- Recommended image size: Square aspect ratio for best display
- Large images may be automatically resized
- Old profile pictures are replaced, not retained

## View Account Details

[IMAGE PLACEHOLDER: screenshot of account details view]

- Users can view their account information and system access details.
- Accessible by: All Authenticated Users

**Steps / How to Use**
1. Log in to your account
2. Navigate to Settings → Profile or `/settings/profile`
3. View the following details:
   - Account creation date
   - Last updated date
   - Account role (User, Admin)
   - Account status (Active, Inactive)
4. Some fields may be read-only for security reasons

**Notes**
- Account role determines what features you can access
- Contact an administrator if you need to update restricted fields
- Account details are retrieved from the server in real-time
