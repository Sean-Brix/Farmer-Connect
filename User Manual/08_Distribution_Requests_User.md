# DISTRIBUTION REQUESTS (USER)

## Browse Distribution Items

[IMAGE PLACEHOLDER: screenshot of distribution items catalog]

- Users can view available items for distribution (seeds, fertilizers, equipment, etc.).
- Accessible by: All Authenticated Users

**Steps / How to Use**
1. Log in to your account
2. Navigate to "Distributions" from the main menu
3. Browse the catalog of available items displayed as cards showing:
   - Item photo
   - Item name
   - Brief description
   - Available quantity
   - Category/type
4. Use search bar to find specific items
5. Filter by category or availability
6. Click on any item card to view full details

**Notes**
- Only items with available stock are open for requests
- Out-of-stock items may be visible but not requestable
- Stock quantities update in real-time as requests are approved

---

## View Distribution Item Details

[IMAGE PLACEHOLDER: screenshot of item details modal]

- View comprehensive information about a distribution item before requesting.
- Accessible by: All Authenticated Users

**Steps / How to Use**
1. From the Distributions catalog, click on an item card
2. A detailed view will display showing:
   - Full item name
   - Complete description
   - Available quantity and unit
   - Category
   - Distribution terms or conditions (if any)
   - Request limits (max quantity per request)
3. Review all information
4. Click "Request" button to proceed with a distribution request
5. Click "Close" to return to the catalog

**Notes**
- "Request" button is disabled if item is out of stock
- You cannot request more than the available quantity
- Some items may have request limits per user or per period

---

## Submit Distribution Request

[IMAGE PLACEHOLDER: screenshot of distribution request form]

- Request distribution items from the available catalog.
- Accessible by: All Authenticated Users

**Steps / How to Use**
1. From the Item Details page, click "Request" button
2. A request form will appear
3. Fill in the required information:
   - **Quantity**: How many units you need (within available stock)
   - **Pickup Date**: When you plan to collect the item (if applicable)
   - **Purpose/Reason**: Brief explanation of why you need the item (optional)
4. Review your request details
5. Click "Submit Request" button
6. A confirmation message will appear indicating your request was submitted

**Notes**
- Your request is initially in "Pending" status awaiting admin approval
- You will be notified when your request is approved or rejected
- You can only request quantities up to the maximum allowed per request
- Multiple requests for the same item may be restricted

## View My Distribution Requests

[IMAGE PLACEHOLDER: screenshot of my distribution requests page]

- View the status of all your submitted distribution requests.
- Accessible by: All Authenticated Users

**Steps / How to Use**
1. Navigate to "My Requests" or "Distribution History" section
2. View your request history organized by status:
   - **Pending**: Requests awaiting administrator review
   - **Approved**: Requests approved and ready for pickup
   - **Rejected**: Requests that were declined
   - **Completed**: Items you have already picked up
3. Each request shows:
   - Item name
   - Quantity requested
   - Request date
   - Status with color coding
   - Administrator notes (if any)
4. Click on any request to view full details

**Notes**
- Status updates appear automatically when administrators take action
- Approved requests show pickup instructions or schedules
- Rejected requests include reasons from the administrator
- You can filter requests by status for easier navigation

## Cancel Distribution Request

[IMAGE PLACEHOLDER: screenshot of cancel request confirmation]

- Cancel a pending distribution request if you no longer need the item.
- Accessible by: All Authenticated Users

**Steps / How to Use**
1. Navigate to "My Requests"
2. Locate the pending request you want to cancel
3. Click "Cancel Request" button next to the request
4. A confirmation dialog will ask you to confirm the cancellation
5. Click "Yes, Cancel" to proceed, or "No" to keep the request active
6. Upon confirmation, the request is cancelled and removed from the pending queue

**Notes**
- You can only cancel requests that are still in "Pending" status
- Approved requests may not be cancellable (contact administrator)
- Cancellation frees up the requested quantity for other users
- You can submit a new request later if needed
