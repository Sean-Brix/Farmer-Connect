# INQUIRY & CHAT SUPPORT (ADMIN)

## Inquiries Management Page

[IMAGE PLACEHOLDER: screenshot of inquiries management page]

- Administrators can view, manage, and respond to user inquiries and support requests.
- Accessible by: Admin, Super Admin only

**Steps / How to Use**
1. Log in as an Administrator
2. Navigate to "Inquiries" or "Chat" from the admin sidebar menu
3. View all inquiries displayed in a list format showing:
   - User name and profile picture
   - Inquiry subject or first message
   - Status (Open, In Progress, Resolved)
   - Creation date
   - Last activity timestamp
   - Unread message count
4. Filter inquiries by status:
   - All
   - Open (new, unassigned)
   - In Progress (being handled)
   - Resolved (completed)
5. Search for specific inquiries by user name or keywords
6. Click on any inquiry to open the conversation thread

**Notes**
- New inquiries are highlighted for immediate attention
- Unread messages show with notification badges
- Inquiries are sorted by most recent activity by default
- Real-time updates via polling keep the list current

## View Inquiry Details & Messages

[IMAGE PLACEHOLDER: screenshot of inquiry conversation view]

- View the complete conversation thread for a specific inquiry.
- Accessible by: Admin, Super Admin only

**Steps / How to Use**
1. From the Inquiries list, click on an inquiry to open it
2. The conversation view displays:
   - User information (name, contact details)
   - Inquiry subject and category
   - Complete message history (chronological order)
   - File attachments (if any)
   - Inquiry status and timestamps
3. Scroll through messages to understand the issue
4. Click on attachments to view or download files
5. Use the reply form at the bottom to respond

**Notes**
- Messages are displayed in chat-like format for easy reading
- Your messages and user messages are visually distinguished
- Timestamps show when each message was sent
- File previews may be available for image attachments

## Respond to Inquiry

[IMAGE PLACEHOLDER: screenshot of inquiry reply form]

- Send messages to users to answer their questions or provide support.
- Accessible by: Admin, Super Admin only

**Steps / How to Use**
1. Open an inquiry conversation
2. Type your response in the message input field at the bottom
3. Optionally attach files:
   - Click the "Attach File" button
   - Select files from your device (images, documents)
   - Multiple files can be attached (up to 5 per message)
4. Review your message for clarity and accuracy
5. Click "Send" button to submit your response
6. Your message appears immediately in the conversation thread
7. User receives notification of your reply (if notifications enabled)

**Notes**
- Supported file types: Images (JPG, PNG), Documents (PDF, DOCX)
- Maximum file size limits may apply
- Messages cannot be edited after sending
- Professional and courteous communication is expected

## Change Inquiry Status

[IMAGE PLACEHOLDER: screenshot of status update controls]

- Update the status of inquiries as you progress through resolution.
- Accessible by: Admin, Super Admin only

**Steps / How to Use**
1. Open an inquiry conversation
2. Locate the status dropdown or status buttons (usually at the top)
3. Select the appropriate status:
   - **Open**: Initial status, awaiting action
   - **In Progress**: Currently being worked on
   - **Resolved**: Issue has been addressed and closed
4. Click "Update Status" or the status automatically saves
5. Optionally add a note about why the status changed
6. Status change is logged and visible to the user

**Notes**
- Changing to "Resolved" closes the inquiry
- Users may be able to reopen resolved inquiries if needed
- Status transitions are tracked for reporting and analytics
- Keeping statuses updated helps manage workload effectively

## Resolve/Close Inquiry

[IMAGE PLACEHOLDER: screenshot of resolve inquiry confirmation]

- Mark an inquiry as resolved when the user's issue has been addressed.
- Accessible by: Admin, Super Admin only

**Steps / How to Use**
1. After fully addressing the user's concern, open the inquiry
2. Click "Resolve" or "Close Inquiry" button
3. A confirmation dialog may appear
4. Optionally add a final summary or resolution notes
5. Click "Confirm" to mark as resolved
6. Inquiry status changes to "Resolved" and is moved to the resolved section
7. User may receive notification that their inquiry has been closed

**Notes**
- Resolved inquiries are archived but remain accessible for reference
- Users can view resolved inquiries in their inquiry history
- Resolved status helps track support efficiency and workload
- If the issue resurfaces, the inquiry can be reopened

## View Unread Count

[IMAGE PLACEHOLDER: screenshot showing unread message indicators]

- Quickly identify how many inquiries have unread messages requiring attention.
- Accessible by: Admin, Super Admin only

**Steps / How to Use**
1. The main Inquiries page shows an unread count badge
2. Individual inquiries with unread messages show notification indicators
3. Unread count updates automatically as new messages arrive
4. Click on inquiries with unread badges to view new messages
5. Messages are marked as read when you open the conversation

**Notes**
- Unread count helps prioritize response efforts
- Real-time updates ensure you don't miss urgent inquiries
- Badge disappears once all messages in an inquiry are read
- System differentiates between admin-read and user-read status
