# LANDING PAGE & NAVIGATION

## Landing Page (Home)

[IMAGE PLACEHOLDER: screenshot of landing page]

- The landing page is the first page users see after logging in, providing quick access to all system features.
- Accessible by: All Authenticated Users

**Steps / How to Use**
1. After logging in, you are automatically redirected to the landing page (or dashboard)
2. View quick navigation cards or menu items for main features:
   - Seminars/Training Programs
   - Distribution Requests
   - Equipment Catalog (EIC)
   - Surveys
   - Inquiries/Support
   - Profile Settings
3. View any announcements or important notices displayed at the top
4. Check notifications or alerts (if notification indicators are present)
5. Click on any feature card or menu item to navigate to that section

**Notes**
- Landing page layout may differ for Admin users (shows admin dashboard)
- Quick stats or dashboard widgets may be displayed
- Navigation menu is always accessible from the header or sidebar

## Main Navigation Menu

[IMAGE PLACEHOLDER: screenshot of navigation menu]

- The navigation menu provides access to all system features and pages.
- Accessible by: All Authenticated Users (menu items vary by role)

**Steps / How to Use**
1. Locate the navigation menu:
   - **Desktop**: Sidebar on the left side of the screen
   - **Mobile**: Hamburger menu icon in the top-left corner
2. Click on any menu item to navigate to that section:
   - Home/Dashboard
   - Seminars
   - Distributions
   - Equipment Catalog (EIC)
   - Surveys
   - Inquiries/Chat Support
   - About
   - FAQ
   - Contact
   - Settings
3. On mobile, click the hamburger icon to open/close the menu
4. Active page is highlighted in the menu

**Notes**
- Admin users see additional menu items (Analytics, User Management, Logs, etc.)
- Menu is responsive and adapts to screen size
- Icons help identify menu items quickly
- Sub-menus may expand when hovering or clicking on parent items

## User Profile Dropdown

[IMAGE PLACEHOLDER: screenshot of profile dropdown]

- Quick access to account settings and logout from any page.
- Accessible by: All Authenticated Users

**Steps / How to Use**
1. Locate your profile picture or username in the top-right corner of the page
2. Click on your profile picture/name to open the dropdown menu
3. Menu options typically include:
   - View Profile
   - Account Settings
   - Preferences
   - Change Password
   - Logout
4. Click on any option to navigate to that page or perform that action
5. Click outside the dropdown to close it without selecting

**Notes**
- Profile picture shows your uploaded photo or default avatar
- Username or role is displayed next to the picture
- Logout option safely ends your session

## Notifications Panel

[IMAGE PLACEHOLDER: screenshot of notifications panel]

- View system notifications and alerts about your activity.
- Accessible by: All Authenticated Users

**Steps / How to Use**
1. Locate the notification bell icon in the top navigation bar
2. Unread notification count is shown as a badge on the icon
3. Click the bell icon to open the notifications panel
4. View recent notifications including:
   - Seminar enrollment confirmations
   - Distribution request status updates
   - EIC borrow approvals/rejections
   - Survey invitations
   - Inquiry responses from administrators
5. Click on any notification to view details or navigate to the related page
6. Click "Mark all as read" to clear unread indicators
7. Click outside the panel to close it

**Notes**
- Notifications are sorted by most recent first
- Unread notifications are highlighted or bolded
- Older notifications may be auto-archived after a certain period
- Notification preferences can be adjusted in Settings

## Search Functionality

[IMAGE PLACEHOLDER: screenshot of global search]

- Some pages include search functionality to quickly find specific items or records.
- Accessible by: All Authenticated Users (availability varies by page)

**Steps / How to Use**
1. Locate the search bar on the page (usually at the top)
2. Click in the search field and type your search query
3. Results filter automatically as you type (debounced for performance)
4. Press Enter or click the search icon to execute the search
5. View filtered results in the list/table below
6. Clear the search field to view all items again

**Notes**
- Search works on page-specific content (e.g., searching seminars on the Seminars page)
- Search is case-insensitive for user convenience
- Some pages have additional filter options alongside search
- Search criteria are preserved while navigating between pages of results

## Breadcrumb Navigation

[IMAGE PLACEHOLDER: screenshot of breadcrumbs]

- Some pages display breadcrumbs showing your current location in the site hierarchy.
- Accessible by: All Authenticated Users

**Steps / How to Use**
1. Look for the breadcrumb trail near the top of the page
2. Breadcrumbs show the navigation path (e.g., Home > Seminars > Seminar Details)
3. Click on any breadcrumb link to navigate back to that level
4. Current page is typically not clickable (shown as plain text)

**Notes**
- Breadcrumbs help you understand where you are in the system
- Useful for quickly navigating back to parent pages
- Especially helpful in multi-level sections like admin dashboard
