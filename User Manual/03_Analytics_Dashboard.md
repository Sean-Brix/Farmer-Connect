# ANALYTICS DASHBOARD (ADMIN)

## Analytics Overview Page

[IMAGE PLACEHOLDER: screenshot of analytics dashboard]

- The analytics dashboard provides comprehensive insights into system usage, user activity, and key performance metrics.
- Accessible by: Admin, Super Admin only

**Steps / How to Use**
1. Log in as an Administrator
2. The Analytics page is typically the default landing page after login
3. Or navigate to "Analytics" from the admin sidebar menu
4. View various charts, graphs, and statistics including:
   - Total registered users
   - Active seminars and enrollments
   - Distribution requests and statuses
   - EIC equipment borrowing statistics
   - Survey participation rates
   - Planting report submissions
   - System activity trends over time

**Notes**
- Data is updated in real-time or with periodic refresh
- You can filter data by date ranges (daily, weekly, monthly, yearly)
- Charts are interactive - hover or click for detailed information
- Export options may be available for reporting purposes
- Some metrics require sufficient data to display meaningful insights

## User Activity Statistics

[IMAGE PLACEHOLDER: screenshot of user activity section]

- View detailed statistics about user engagement and system usage patterns.
- Accessible by: Admin, Super Admin only

**Steps / How to Use**
1. Navigate to the Analytics Dashboard
2. Scroll to the "User Activity" or "Engagement" section
3. View metrics such as:
   - Daily active users
   - New user registrations over time
   - User login frequency
   - Most active users
4. Use date range filters to analyze specific time periods
5. Click on data points for more detailed breakdowns

**Notes**
- Activity is tracked automatically as users interact with the system
- Privacy settings ensure individual user data is aggregated appropriately
- Trends help identify peak usage times and user engagement patterns

## Service Usage Reports

[IMAGE PLACEHOLDER: screenshot of service usage reports]

- Track usage statistics for each major service (Seminars, Distributions, EIC, Surveys, etc.).
- Accessible by: Admin, Super Admin only

**Steps / How to Use**
1. From the Analytics Dashboard, locate the "Service Usage" section
2. Review usage statistics for each module:
   - Seminar enrollments and attendance rates
   - Distribution request volumes
   - EIC equipment borrowing trends
   - Survey response rates
   - Planting report submissions
3. Compare services side-by-side to identify popular features
4. Use filters to drill down into specific services or time frames

**Notes**
- Service usage helps administrators allocate resources effectively
- Low usage may indicate need for user training or feature improvements
- High-demand services may require capacity planning
