# EIC - EQUIPMENT & ITEM CATALOG (USER)

## Browse Equipment Catalog

[IMAGE PLACEHOLDER: screenshot of EIC catalog page]

- Users can browse and search for equipment and items available for borrowing.
- Accessible by: All Authenticated Users

**Steps / How to Use**
1. Log in to your account
2. Navigate to "EIC" or "Equipment Catalog" from the main menu
3. Browse the catalog of available items displayed as cards showing:
   - Item photo
   - Item name
   - Brief description
   - Available quantity
   - Category
4. Use search bar to find specific equipment
5. Filter by category or availability
6. Click on any item card to view full details and request

**Notes**
- Only items with available stock can be requested
- Out-of-stock items are clearly marked
- Stock updates in real-time as requests are approved and items are returned

## View Equipment Details

[IMAGE PLACEHOLDER: screenshot of equipment details modal]

- View comprehensive information about equipment before requesting to borrow.
- Accessible by: All Authenticated Users

**Steps / How to Use**
1. From the Equipment Catalog, click on an item card
2. A detailed modal will display showing:
   - Full item name and description
   - Item specifications or usage instructions
   - Available quantity
   - Category
   - Your current borrow status for this item (if applicable)
3. Review all information
4. Click "Request to Borrow" button to proceed with a request
5. Click "Close" to return to the catalog

**Notes**
- "Request to Borrow" button is disabled if item is out of stock
- You cannot request if you already have an active request for this item
- Maximum simultaneous borrows limit applies across all items

## Submit Equipment Borrow Request

[IMAGE PLACEHOLDER: screenshot of borrow request form]

- Request to borrow equipment from the catalog.
- Accessible by: All Authenticated Users

**Steps / How to Use**
1. From the Equipment Details modal, click "Request to Borrow" button
2. A request form will appear with the following fields:
   - **Quantity**: How many units you need (within available stock and max per request)
   - **Pickup Date** (required): When you plan to collect the item
   - **Return Date** (required): When you will return the item
   - **Purpose/Reason**: Why you need the equipment (optional but recommended)
3. Select appropriate dates from the calendar pickers
4. Ensure return date is after pickup date
5. Review your request details
6. Click "Submit Request" button
7. A confirmation message will appear indicating your request was submitted

**Notes**
- Your request starts in "Pending" status awaiting admin approval
- You will be notified when your request is approved or rejected
- Quantity is limited by system settings (max quantity per request)
- You cannot have more than the maximum allowed simultaneous active borrows
- After returning an item, you can immediately request it again (no cooldown period)

## View My Borrow Requests

[IMAGE PLACEHOLDER: screenshot of my borrow requests page]

- View the status of all your equipment borrowing requests.
- Accessible by: All Authenticated Users

**Steps / How to Use**
1. Navigate to "My Requests" or "Borrow History" section
2. View your request history organized by status:
   - **Pending**: Requests awaiting administrator approval
   - **Approved/Ready**: Requests approved and ready for pickup
   - **Borrowed**: Items currently in your possession
   - **Returned**: Items you have returned (completed)
   - **Rejected/Cancelled**: Declined or cancelled requests
3. Each request shows:
   - Item name and photo
   - Quantity
   - Pickup date
   - Return date (and days remaining/overdue)
   - Status with color coding
   - Administrator notes (if any)
4. Click on any request to view full details

**Notes**
- Active borrowed items show countdown to return date
- Overdue items are highlighted with urgent warnings
- Return reminders may be sent automatically as due date approaches
- Status updates appear in real-time when administrators take action

## Cancel Equipment Request

[IMAGE PLACEHOLDER: screenshot of cancel request confirmation]

- Cancel a pending borrow request if you no longer need the equipment.
- Accessible by: All Authenticated Users

**Steps / How to Use**
1. Navigate to "My Requests"
2. Locate the pending request you want to cancel
3. Click "Cancel Request" button next to the request
4. A confirmation dialog will ask you to confirm the cancellation
5. Click "Yes, Cancel" to proceed, or "No" to keep the request active
6. Upon confirmation, the request is cancelled and removed from the pending queue

**Notes**
- You can only cancel requests that are still in "Pending" status
- Approved requests or items already picked up cannot be self-cancelled (contact administrator)
- Cancellation frees up the reserved quantity for other users
- You can submit a new request later if needed

## Track Return Deadline

[IMAGE PLACEHOLDER: screenshot showing return deadline information]

- Monitor when you need to return borrowed equipment to avoid being overdue.
- Accessible by: All Authenticated Users

**Steps / How to Use**
1. Navigate to "My Requests" or view active borrows from your dashboard
2. Locate items with "Borrowed" status
3. View the return date and days remaining for each borrowed item
4. Items due soon (within 3 days) are highlighted with warnings
5. Overdue items are marked with urgent alerts
6. Plan to return items before or on the due date

**Notes**
- You may receive automated reminder notifications before the due date
- Late returns may affect your ability to borrow in the future
- Contact administrators if you need an extension before the due date
- Return items on time to maintain good standing and help others access equipment
