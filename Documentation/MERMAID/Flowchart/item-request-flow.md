# Item Request Flow

This flowchart shows the complete process for requesting and managing agricultural equipment through both EIC and Distribution systems.

## Request Types

### EIC (Equipment in Circulation)
- **Purpose**: Temporary lending of agricultural equipment
- **Return Required**: Items must be returned within specified timeframe
- **Monitoring**: System tracks pickup and return dates
- **Status Management**: Items cycle between Available and EIC status

### Distribution System
- **Purpose**: Permanent distribution of agricultural items
- **Ownership Transfer**: Items are given permanently to farmers
- **Support Programs**: Government and NGO assistance programs
- **Final Status**: Items marked as "Distributed" (no return required)

## Process Flow

### Request Submission
1. **User Selection**: Choose between EIC or Distribution
2. **Item Selection**: Browse and select from available equipment
3. **Quantity Specification**: Request needed amounts
4. **Additional Information**: Notes and return dates (EIC only)

### Admin Review Process
1. **Request Evaluation**: Admin reviews request details
2. **Inventory Check**: Verify item availability and quantities
3. **Decision Making**: Approve or reject based on criteria
4. **Communication**: Notify users of decision and next steps

### Fulfillment Process
1. **Pickup Scheduling**: Coordinate item collection
2. **Status Updates**: Real-time tracking of item status
3. **Return Management**: Monitor and enforce return dates (EIC)
4. **Completion**: Final status updates and system reconciliation

## Key Features

- **Dual System Support**: Handles both temporary and permanent distributions
- **Admin Oversight**: All requests require administrative approval
- **Status Tracking**: Complete lifecycle management of all items
- **Return Monitoring**: Automated tracking of EIC return deadlines
