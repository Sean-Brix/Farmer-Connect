# Equipment Management Use Cases

This diagram illustrates all use cases related to agricultural equipment management through both EIC and Distribution systems.

## Actor: Farmer/User

### EIC (Equipment in Circulation) Services
- **Browse EIC Items**: View available equipment for temporary use
- **Request EIC Item**: Submit request for equipment lending
- **View EIC Requests**: Check status of submitted EIC requests
- **Cancel EIC Request**: Withdraw pending EIC requests
- **Return EIC Item**: Process return of borrowed equipment

### Distribution Services
- **Browse Distribution Items**: View items available for permanent distribution
- **Request Distribution Item**: Submit request for permanent equipment
- **View Distribution Requests**: Monitor distribution request status
- **Cancel Distribution Request**: Withdraw pending distribution requests
- **Confirm Item Pickup**: Acknowledge receipt of distributed items

### Request Management
- **Track Request Status**: Monitor real-time status of all requests
- **View Request History**: Access complete request transaction history
- **Update Pickup Schedule**: Modify collection dates and times
- **Submit Request Notes**: Add additional information to requests

## System Features

### EIC System
- **Temporary Lending**: Short-term equipment access with return requirements
- **Return Tracking**: Automated monitoring of return deadlines
- **Availability Management**: Real-time equipment availability status

### Distribution System
- **Permanent Transfer**: Equipment given permanently to farmers
- **Support Programs**: Government and NGO assistance initiatives
- **Ownership Transfer**: Complete equipment ownership change

## Request Lifecycle

1. **Discovery**: Browse available equipment catalog
2. **Request**: Submit detailed equipment request
3. **Review**: Administrative approval process
4. **Fulfillment**: Equipment pickup and delivery
5. **Completion**: Return (EIC) or permanent transfer (Distribution)

## Key Benefits

- **Equipment Access**: Affordable access to agricultural tools
- **Support Programs**: Government assistance for farmer development
- **Flexible Options**: Both temporary and permanent equipment solutions
- **Transparent Process**: Clear tracking and status updates throughout
