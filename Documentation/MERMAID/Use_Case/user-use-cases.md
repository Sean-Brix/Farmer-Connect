# User Use Cases

This diagram shows all the use cases available to regular farmers and users in the Farmer-Connect system.

## Actor: Farmer/User

### Authentication Use Cases
- **Register Account**: Create new user account with profile information
- **Login**: Authenticate and access system services
- **Logout**: Terminate session and secure account
- **Reset Password**: Recover account access through password reset

### Profile Management Use Cases
- **View Profile**: Display current user profile information
- **Edit Profile**: Update personal and contact information
- **Upload Profile Picture**: Add or change profile photo
- **Manage Commodities**: Select agricultural commodities of interest

### Seminar Services Use Cases
- **Browse Seminars**: View available educational seminars
- **Register for Seminar**: Enroll in training programs
- **Cancel Registration**: Withdraw from seminar enrollment
- **View Registration Status**: Check current enrollment status

## Key Features

- **Self-Service**: Users can independently manage their profiles and enrollments
- **Educational Access**: Direct access to training and capacity building programs
- **Profile Customization**: Comprehensive profile management capabilities
- **Commodity Tracking**: Link users to their specific agricultural interests

## User Journey

1. **Onboarding**: Registration and profile setup
2. **Discovery**: Browse available seminars and services
3. **Engagement**: Register for relevant training programs
4. **Management**: Ongoing profile and enrollment management
