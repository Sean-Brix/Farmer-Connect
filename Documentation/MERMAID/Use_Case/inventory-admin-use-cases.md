# Inventory Administration Use Cases

This diagram shows the comprehensive inventory management capabilities available to administrators and super administrators.

## Actors

### Administrator
- **Role**: System managers and agricultural office staff
- **Permissions**: Full inventory management and request processing
- **Responsibilities**: Day-to-day inventory operations and user support

### Super Administrator
- **Role**: Senior system administrators
- **Permissions**: All administrative functions plus system-wide controls
- **Responsibilities**: High-level system management and oversight

## Use Cases

### Item Management
- **Add Inventory Item**: Create new equipment entries in the system catalog
- **Edit Item Details**: Modify item descriptions, categories, and specifications
- **Delete Item**: Remove items from the system (Super Admin only)
- **Upload Item Images**: Add visual documentation for equipment
- **Categorize Items**: Organize items by type and agricultural purpose

### Stack Management
- **Create Item Stacks**: Generate quantity batches for inventory items
- **Edit Stack Quantities**: Adjust available quantities and stock levels
- **Update Stack Status**: Change item availability and condition status
- **Transfer Stack Items**: Move items between different status categories
- **Delete Stack**: Remove specific item batches from inventory

### Request Processing
- **Review EIC Requests**: Evaluate temporary equipment lending requests
- **Approve/Reject EIC**: Make decisions on equipment lending applications
- **Review Distribution Requests**: Assess permanent equipment distribution requests
- **Approve/Reject Distribution**: Decide on equipment distribution applications
- **Schedule Pickups**: Coordinate equipment collection with approved users
- **Track Returns**: Monitor and manage EIC equipment return schedules

## Administrative Workflow

### Inventory Setup
1. **Item Creation**: Add new equipment to system catalog
2. **Stack Generation**: Create quantity batches for tracking
3. **Status Management**: Set availability and condition status
4. **Media Upload**: Add images and documentation

### Request Management
1. **Request Review**: Evaluate user equipment requests
2. **Decision Making**: Approve or reject based on availability and criteria
3. **Coordination**: Schedule pickups and manage logistics
4. **Tracking**: Monitor equipment status and return schedules

## Key Features

- **Comprehensive Control**: Complete inventory lifecycle management
- **Batch Management**: Flexible quantity and condition tracking
- **Request Workflow**: Systematic approval and fulfillment process
- **Status Tracking**: Real-time equipment availability monitoring
- **Role-based Access**: Different permission levels for system security
